# FIFA 2026 Player & Club Performance Analytics

## Project Overview

This project is an end-to-end Data Analytics project focused on analyzing FIFA 2026 player and club performance data.

The objective is to transform raw football performance data into meaningful business-style insights using **Python, SQL, and Power BI**.

The analysis covers player performance, attacking contribution, positional analysis, club performance, competition contribution, player efficiency, and performance patterns.

---

## Business Objectives

- Evaluate overall player performance and consistency.
- Identify high-performing players based on performance metrics.
- Analyze attacking contribution across playing positions.
- Compare club-level goal contributions.
- Understand contribution across competitions.
- Analyze player efficiency using per-90 metrics.
- Identify relationships between performance, playing time, and market value.
- Build an interactive management-ready Power BI dashboard.

## Key Insights

The analysis highlights several important patterns:

- Player contribution varies significantly across playing positions.
- Per-90 metrics provide a more comparable view of attacking efficiency than raw totals alone.
- Goal contribution is concentrated among specific attacking positions.
- Club-level contribution varies considerably across teams.
- Competition-level contribution is unevenly distributed.
- Performance analysis benefits from combining match rating, efficiency metrics, playing time, and contribution rather than relying on a single metric.
