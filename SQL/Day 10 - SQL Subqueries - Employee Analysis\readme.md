## Day 10 – SQL Subqueries

### 📌 Overview

Day 10 focuses on SQL Subqueries and how queries can be used inside another SQL query to solve analytical problems.

### 📚 Topics Covered

* Basic Subqueries
* Scalar Subqueries
* MAX() with Subqueries
* MIN() with Subqueries
* AVG() with Subqueries
* Finding highest salary
* Finding lowest salary
* Finding employees above average salary
* Finding customers below average balance
* Finding customers above average balance
* Second highest value using a Subquery
* Subqueries with WHERE
* Subqueries with ALL
* Subqueries with ANY
* Correlated Subqueries

### 💼 Practical Projects

#### 1. Employee Salary Subqueries

File: `Day10_Subqueries_Employee.sql`

Practiced subqueries using an Employee table to identify employees with the maximum salary, minimum salary, and salaries above the average salary.

#### 2. Customer Balance Subquery Practice

File: `Day10_Subqueries_Practice.sql`

Practiced business-oriented customer balance analysis using subqueries, including average balance comparisons, minimum and maximum balances, marital-status-based analysis, ALL, ANY, and correlated subqueries.

### 🎯 Learning Objective

The objective of Day 10 was to understand how a SQL query can be nested inside another query and how subqueries can be used to solve real-world data analysis problems.

### 💼 Business Applications

Subqueries can be used for:

* Finding employees with above-average salaries
* Finding highest and lowest values
* Customer balance analysis
* Comparing customers against business averages
* Comparing groups within a dataset
* Identifying records based on calculated benchmarks
* Performing advanced filtering and analytical queries
