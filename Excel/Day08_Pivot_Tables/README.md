## Pivot Table Structure

### Rows

Used to organize categories or groups.

Examples:

- Region
- Category
- Product
- Department

### Columns

Used to compare data across another dimension.

Examples:

- Year
- Segment
- Category

### Values

Used to calculate numerical information.

Examples:

- Sales
- Profit
- Quantity

### Filters

Used to filter the entire Pivot Table.

Examples:

- Year
- Region
- Category

## Business Applications
