# Day 10 - Excel Dashboard

## Overview

This is Day 10 of my Excel learning journey.

The focus of this day was creating an interactive business dashboard using Pivot Tables, Pivot Charts, Slicers, and KPI cards.

## Topics Covered

- Excel Dashboard
- KPI Cards
- Pivot Tables
- Pivot Charts
- Slicers
- Report Connections
- Interactive Filtering
- Sales Analysis
- Profit Analysis
- Quantity Analysis
- Regional Analysis
- Category Analysis
- Year Analysis
- Segment Analysis

## KPI Cards

Created KPIs for:

- Total Sales
- Total Profit
- Total Quantity
- Total Orders

## Dashboard Charts

Created visualizations for:

- Sales by Region
- Sales by Category
- Profit by Region
- Monthly Sales Trend
- Sales by Segment

## Slicers

Created interactive slicers for:

- Region
- Category
- Year
- Segment

## Dashboard Interactivity

Connected slicers to multiple Pivot Tables and Pivot Charts using Report Connections.

This allows all connected reports to update when a user selects a filter.

## Business Questions

The dashboard helps answer:

- What are the total sales?
- What is the total profit?
- Which region has the highest sales?
- Which category has the highest sales?
- Which region generates the highest profit?
- How are sales changing over time?
- Which customer segment generates the most sales?
- How does performance change when filters are applied?
