# Day 2 - Basic Excel Formulas

## Overview

This is Day 2 of my Excel learning journey.

The focus of this day was learning basic Excel formulas used for calculations and summary analysis.

## Topics Covered

### Basic Mathematical Functions

* SUM
* AVERAGE
* MIN
* MAX

### Counting Functions

* COUNT
* COUNTA
* COUNTBLANK

### Basic Calculations

* Addition
* Subtraction
* Multiplication
* Division
* Percentage calculations

### Cell References

* Relative cell references
* Using cell references in formulas
* Copying formulas across rows and columns

## Example Formulas

```excel
=SUM(B2:B10)
=AVERAGE(B2:B10)
=MIN(B2:B10)
=MAX(B2:B10)
=COUNT(B2:B10)
=COUNTA(A2:A10)
=COUNTBLANK(A2:A10)
```

## Skills Learned

* Performing calculations using Excel formulas
* Calculating totals and averages
* Finding minimum and maximum values
* Counting numeric and non-empty values
* Working with cell references
* Creating reusable formulas

## Business Applications

Basic formulas can be used for:

* Total sales calculation
* Average salary analysis
* Highest and lowest sales identification
* Employee counting
* Product quantity analysis
* Basic business reporting

Created a sample business dataset and applied basic Excel formulas to calculate totals, averages, minimum values, maximum values, and record counts.
