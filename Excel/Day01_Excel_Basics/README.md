# Day 1 - Excel Basics

## Overview

This is Day 1 of my Excel learning journey as part of my transition from SQL DBA to Data Analyst.

The focus of this day was understanding the Excel interface, workbook structure, cells, ranges, references, formatting, and basic spreadsheet operations.

## Topics Covered

### 1. Excel Basics

* Workbook
* Worksheet
* Rows
* Columns
* Cells
* Cell ranges
* Formula bar
* Name box

### 2. Data Entry

* Entering text
* Entering numbers
* Entering dates
* Editing cell values
* Copy and paste
* Autofill

### 3. Cell References

* Relative cell reference
* Absolute cell reference
* Mixed cell reference

### 4. Basic Formatting

* Font formatting
* Font size
* Bold and italic
* Cell borders
* Cell fill
* Alignment
* Number formatting
* Currency formatting
* Percentage formatting

### 5. Basic Excel Operations

* Sorting data
* Filtering data
* Adjusting column width
* Adjusting row height
* Freeze Panes

## Skills Learned

* Navigating an Excel workbook
* Managing worksheets
* Working with cells and ranges
* Entering and formatting data
* Understanding cell references
* Preparing data for analysis
* Using basic Excel data management features

## Practice

Created a basic employee/sales dataset and practiced:

* Data entry
* Formatting
* Sorting
* Filtering
* Cell references
* Basic spreadsheet organization

## Data Analyst Relevance

These Excel fundamentals are important for preparing and organizing data before performing analysis, creating Pivot Tables, building dashboards, and generating business insights.
